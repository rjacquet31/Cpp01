# C++ Module 01

> **42 cursus** · C++ · object-oriented programming module.

Part of the C++ learning modules at 42. Memory allocation, pointers to members, references and the `switch` statement.

## Features

- Multiple exercises (`ex00`, `ex01`, …), each in its own folder
- Compiled with `c++ -Wall -Wextra -Werror -std=c++98`

## Build

```bash
cd ex00 && make    # build a single exercise
```

## Usage

```bash
./<exercise_executable>
```

## Key concepts

Memory management and references in C++.
